# Stride & Form — Shoe Shop

A responsive, animated footwear storefront landing page built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Editorial campaign hero and original generated product photography.
- Four shoe collections: everyday, running, trail, and dress.
- Product category filters and live search.
- Save-for-later heart buttons, interactive demo shopping bag, and newsletter confirmation.
- Responsive navigation and layouts, reduced-motion support, and accessible labels.

## Run locally

```bash
pnpm install
pnpm dev
```

## Demo limitations

This is a front-end landing-page prototype. Checkout, product inventory, customer accounts, and newsletter sign-up are demo interactions and are not connected to a commerce backend or mailing service.
